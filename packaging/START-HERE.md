# Studio Standalone — start here

Double-click Start-Studio.bat. First launch needs Python 3.11–3.13 and internet
access to install dependencies. The launcher can select a supported installed
Python when the default is older. Configure generation-model folders in Settings.
Keep the app folder and start_studio.py alongside the launcher.

- [Tester guide](app/docs/studio/FRIENDS_ALPHA_TESTER_GUIDE.md)
- [Usable features and limitations](app/docs/studio/TESTER_FEATURE_STATUS.md)
- [Release notes](app/docs/studio/FRIENDS_ALPHA_RELEASE_NOTES.md)
- [License and credits](app/docs/studio/THIRD_PARTY_NOTICES.md)

The five Auto Detail detectors and Remacri upscaler are included. Checkpoints,
text encoders, VAEs and personal data are not included. This is an unfinished
Windows/NVIDIA tester candidate; keep backups of your artwork.

The separate -source.zip is for source review and development. You do not need
to extract it to run Studio. This ZIP contains the runtime Python/JavaScript
source and its required assets. The adjacent manifest lists every file and hash.
