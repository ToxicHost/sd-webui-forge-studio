Auto-save folder

Where generated images are written automatically. This folder is on the machine running Forge Studio. If you’re using Studio remotely, type a path visible to the server/VM, then click Trust folder. Leave blank for Forge’s default output folder.

Performance & VRAM

GPU memory allocation, model residency, and idle cleanup.

VRAM
GPU Weights

How much VRAM to use for model weights. 0 = Forge default. Higher values keep more of the model in VRAM for faster generation; lower values offload weights to RAM to free VRAM for inference. Peak usage during generation may still exceed this — it's a loading budget, not a hard cap.

Auto

10 min
Use GPU tile compositing

Uses GPU memory to composite tiled upscales faster. Studio automatically falls back to CPU compositing when there is not enough safe GPU memory. Turn this off to always use CPU compositing.
